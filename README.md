## ⚙️ How It Works

The application displays a question along with multiple answer choices.

The user selects an answer and moves to the next question.

The application then:

1. Checks the selected answer
2. Updates the score
3. Moves to the next question
4. Updates the progress indicator
5. Continues until all questions are completed
